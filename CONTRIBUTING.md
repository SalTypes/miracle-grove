# Help improve Miracle Grove

Useful contributions include spacing fixes, language proofs, and application test reports. Start with an issue when a change affects several styles.

For a rendering problem, include the exact text and font version. Add your operating system, application, font size, and a screenshot.

If you can, compare the same text with ligatures or kerning disabled. That helps distinguish an outline problem from a shaping problem.

## Submit a change

1. Read the design and build guides.
2. Change the build source rather than editing only a generated font.
3. Build and run the regression tests.
4. Include before-and-after proofs at the affected sizes.
5. Explain any character-width or line-break changes.

Contributions to font software must remain compatible with the SIL Open Font License 1.1. Preserve upstream attribution and disclose any new source material.

Do not add outlines from proprietary fonts. Language additions need proofreading by someone familiar with the writing system.

Keep reports specific and respectful. This is a small project; response times are not guaranteed.
