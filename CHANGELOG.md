# Changelog

## 1.200 · 2026-10-28

- Arched the upright A bridge and raised the M center.
- Refined the h/m/n shoulders, K/R legs, Q tail, r terminal, and e crossbar.
- Replaced the italic l hook with an angled cap and matched the slashed form.
- Reduced the italic f bulbs; related accents and ligatures inherit the revised outlines.
- Preserved spacing, character coverage, and the existing expressive alternates.
- Rebuilt all 8 styles and refreshed the specimen and audit reports.

## 1.100 · 2026-10-28

First public release through SalTypes, following a private 1.000 development build.

- Corrected upright `lj` placement and rebuilt `ł` with the custom returning foot.
- Added tabular figures, proportional-number selection, and ligature caret positions.
- Restored existing Latin character mappings and added two useful spacing characters.
- Harmonized hyphen coverage between upright and italic styles.
- Added style metadata and named the expressive alternate feature.
- Decomposed delivery outlines and corrected left-side bearings.
- Added reproducible builds, public documentation, and regression tests.

## 1.000 · 2026-10-27

Initial development build. Selected Fraunces instances and introduced the custom upright `l` in four weights with matching italics.
